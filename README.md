# netcheck
A simple network availability checker for Linux  
Adding only one directory and desktop file.  


To install app just run
```bash
curl -fsSL https://raw.githubusercontent.com/BUCKSN/netcheck/main/install.sh | sh
```
To remove app run:
```bash
rm -rf $HOME/.local/share/netcheck  
rm -rf $HOME/.local/share/applications/netcheck.desktop
```
